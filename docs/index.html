THE QUESTION

Can a place be heard
before it is seen?

This project explores externalization, apparent distance and intentional spatial uncertainty in a headphone narrative. The first pilot follows Mole into the Wild Wood: distinct events gradually become an uncertain surrounding field, then retreat outside a small shelter.

The full production is planned in REAPER with the IEM Plug-in Suite. This brief browser study demonstrates the interaction and narrative progression. It contains no finished voice recordings, evaluated HRTF selection or validated perceptual results.

What this prototype is doing +

Signal → field → shelter. A fixed event score sends whistles behind and ahead of the listener, then distributes unequal footstep events at different distances. At 16 seconds, exterior events are attenuated and low-pass filtered to sketch enclosure.

Rendering. Web Audio HRTF panners, per-event level and spectral shaping, and two quiet illustrative reflection taps. These are design cues, not a measured forest impulse response or an Ambisonic decoder. The shelter is an occlusion sketch, not a cavity simulation.

Next listening test. Compare level-only distance against combined spectral and reflection cues using the same source and trajectory. Hide the visual map during judgement; perceived externalization and distance require listening evidence. This demo is not a controlled A/B test.
